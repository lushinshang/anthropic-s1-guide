## AI製作聲明

分析、撰稿、翻譯、查證、審稿與圖像重製均由Codex執行環境的GPT-6系列模型及研究代理完成，不是人類分析，未經人工逐句校稿。核對用於文件解讀，不是對公司營運真實性的獨立查核。圖表使用SVG，未用生成式插畫呈現財務資料。

公開檔案包含兩個HTML、兩份Markdown、42張英文原圖及26張繁中SVG。研究、審稿與QA內部紀錄不包含於此儲存庫。
